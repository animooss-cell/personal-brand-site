- متن مقاله‌ها از محیط کار قابل خواندن نبود (دسترسی به سایت و Supabase مسدود بود)؛ برای همین زیر هر مقاله چند مورد «پیش از وارد کردن بررسی کنید» آمده تا توضیحات چیزی بیشتر از متن مقاله وعده ندهد.
